**阻塞条件**:

  - 完成时间: 2026-05-08
  - 优先级: 高
  - 描述: 测量输入延迟 p95，验证是否 < 16ms
  - 验收标准:
    - [x] 连续输入 10 分钟，p95 延迟 < 16ms
    - [x] 光标无跳动、无异常滚动
    - [x] 输入过程中无 React 全量渲染

## 状态说明

### Milestone 状态
- ✅ 已完成 (Completed)
- 🚧 进行中 (In Progress)
- 📋 待办 (Todo)
- ⏸️ 阻塞 (Blocked)

### Issue 状态
- ✅ 已完成 (Completed)
- 🚧 进行中 (In Progress)
- 📋 待办 (Todo)
- ⏸️ 阻塞 (Blocked)
- ❌ 已取消 (Cancelled)

### Issue 优先级
- 高 (High): 阻塞里程碑的关键路径
- 中 (Medium): 重要但非阻塞
- 低 (Low): 可延后处理

---

## 依赖关系

```
Phase 1 完成 → Phase 2 完成 → Phase 3 完成
     ↓              ↓              ↓
Milestone 1.6  Milestone 2.5  Milestone 3.5
```

每个 Phase 内的里程碑有明确的依赖关系，必须按顺序完成。

---

## 工作流

1. **规划**: 从 ROADMAP 定义里程碑
2. **分解**: 将里程碑分解为具体的 Issues
3. **执行**: 按优先级执行关联的 Issues
4. **验证**: 按验收标准逐一验证
5. **总结**: 记录实现要点和挑战
6. **关闭**: 标记里程碑为已完成
7. **推进**: 进入下一个里程碑

---

## 关键原则

- 不跳里程碑，不并行开发
- 每个 Gate 必须通过才能进入下一阶段
- 用户价值验收失败即使工程指标通过也不得判定完成
- 性能回归是阻塞条件
