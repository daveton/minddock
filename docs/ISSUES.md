## Issue 状态说明

- ✅ 已完成 (Completed)
- 🚧 进行中 (In Progress)
- 📋 待办 (Todo)
- ⏸️ 阻塞 (Blocked)
- ❌ 已取消 (Cancelled)

## Issue 优先级

- 高 (High): 阻塞里程碑的关键路径
- 中 (Medium): 重要但非阻塞
- 低 (Low): 可延后处理

## Issue 工作流

1. **规划**: 从 ROADMAP 识别需要的问题
2. **创建**: 在 ISSUES.md 创建 issue
3. **关联**: 关联到具体里程碑
4. **执行**: 按优先级执行
5. **验证**: 按验收标准验证
6. **关闭**: 标记为已完成并总结

## Issue 总结模板

每个完成的 issue 应包含总结：

```markdown
- [x] **ISSUE-N**: 标题
  - 状态: 已完成
  - 完成时间: YYYY-MM-DD
  - 关联里程碑: 里程碑名称
  - 描述: 简要描述
  - 验收: 验收结果
  - 总结: 实现要点、遇到的挑战、解决方案
```
